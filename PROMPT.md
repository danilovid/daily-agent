# Задача для Claude Code: шаг 1, каркас приложения

Ты работаешь в репозитории приложения Daily Agent. Сначала прочитай три файла:

- `CLAUDE.md` — правила проекта. Они действуют во всех сессиях.
- `docs/architecture.md` — архитектура, модель данных и план по шагам.
- `docs/mockups/today.html` — макет экрана «Сегодня». Остальные макеты лежат в той же папке.

## Что сделать

Только шаг 1 из плана: каркас приложения (задача IDA-24).

1. Проверь окружение командой `wails3 doctor`. Нужны Go 1.26 или новее, Node и инструменты командной строки Xcode. Если чего-то не хватает, назови, что нужно поставить, и дождись подтверждения.
2. Создай проект Wails v3 в корне репозитория с интерфейсом на React и TypeScript. Список шаблонов показывает `wails3 init -l`. Закрепи точную версию Wails в `go.mod` и точные версии пакетов в `package.json`.
3. Настрой окно: 1100 × 860, тёмная тема, скрытый заголовок. Кнопки окна стоят над боковой панелью, как в макете.
4. Перенеси из макета «Сегодня» боковую панель и главную область. Цвета, отступы и размеры вынеси в CSS-переменные. Навигация в боковой панели переключает экраны. У разделов без готового экрана пока стоит заглушка с названием.
5. Подключи SQLite через `modernc.org/sqlite`. Файл базы лежит в `~/Library/Application Support/Daily Agent/`. Сделай встроенные миграции и создай таблицы из раздела 5 архитектуры.
6. Экран «Сегодня» читает встречи и задачи из базы через сервис ядра.
7. Добавь две команды: одна наполняет базу вымышленными тестовыми данными, как в макете, другая очищает базу.
8. Напиши тесты на Go: миграции применяются на пустой базе, чтение экрана «Сегодня» возвращает данные за нужный день.

## Чего не делать

- Не подключай OpenCode, чат, обновление данных и настройки. Это следующие шаги.
- Не добавляй сетевых вызовов.
- Не трогай рабочие системы и реальные данные.

## Готово, когда

- `wails3 dev` запускает окно, экран «Сегодня» выглядит как макет и показывает тестовые данные из базы.
- После перезапуска приложения данные на месте.
- `go test ./...` проходит.
- В `README.md` описано, как собрать и запустить приложение.
